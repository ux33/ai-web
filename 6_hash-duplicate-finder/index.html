Поиск дубликатов по хешам

Загрузите файл с хешами или вставьте его содержимое, чтобы найти файлы с одинаковыми хешами.

Исходные данные

Выберите способ передачи данных.

Можно также перетащить файл в эту область. Поддерживается любой тип файла с текстовым содержимым.

Результат

Каждая строка содержит хеш, пробел и путь к файлу. Строки, начинающиеся с ;, считаются комментариями и игнорируются. 

; SHA-1 checksums generated by TeraCopy
; teracopy.com
